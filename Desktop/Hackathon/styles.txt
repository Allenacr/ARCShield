## What most AI SaaS projects default to (the look to avoid)

**Typography**
- Inter, Geist, SF Pro Display, Satoshi — geometric grotesk, everywhere, no hierarchy variation
- Everything medium-weight, tight letter-spacing, rounded terminals
- Gradient text on headlines (usually purple→blue)
- Tiny uppercase eyebrow labels above every heading ("FEATURES", "HOW IT WORKS")

**Icons**
- Lucide / Phosphor / Heroicons — thin 1.5px stroke, rounded corners, perfectly consistent grid
- Icon-in-a-rounded-square container with soft gradient or pastel fill background
- Every feature block gets one: icon + bold title + gray subtitle, repeated in a 3-column grid

**Color/surface**
- Dark mode default, near-black background (#0a0a0a–#111)
- Purple/blue/violet gradient accents, sometimes glassmorphism cards with blurred backdrop
- Soft glow/shadow behind gradient blobs

**Microcopy/voice**
- "Supercharge your workflow with AI"
- "✨ AI-powered" badges, sparkle emoji as a UI element
- Button labels: "Get Started", "Try it Free", "Analyze Now"
- Loading state: generic spinner + "Thinking..." / "Processing..."

**Layout**
- Centered hero, three-column feature grid below, rounded-2xl cards with 1px border + subtle shadow, testimonial carousel, pricing table

## Fresh format for Sleuth — Investigation/Evidence system

**Typography — three-tier system, each tier signals a different kind of information**

| Tier | Use | Style |
|---|---|---|
| Case Display | Case numbers, section headers ("CASE №047") | Condensed editorial serif or slab-grotesk, all-caps, wide tracking — e.g. **Fraunces** (serif, condensed cut) or **Archivo Expanded** |
| Evidence/Data | IDs, timestamps, confidence %, JSON, tags | Monospace — **JetBrains Mono** or **IBM Plex Mono** — always exact, never rounded corners on badges around it |
| Human/Narrative | Body text, findings descriptions, agent commentary | Humanist serif or warm sans for readability — **Newsreader**, **Lora**, or **Source Serif 4** — deliberately *not* a grotesk, to contrast against the mono/display tiers |

No gradient text, ever. Headlines are solid ink-black or deep sepia, never blended color.

**Icons — replace the icon-grid entirely**

Instead of Lucide-in-a-rounded-square:
- **Stamp/seal marks** instead of icons for status ("VERIFIED", "FLAGGED", "REDACTED") — literal circular/rectangular stamp graphics with slight rotation and ink-bleed texture, not vector glyphs
- **Hand-drawn/sketch-style line icons** (single inconsistent stroke weight, like a case annotator drew them) for interactive actions — pin, magnifier, paperclip, string-tie — instead of a perfectly uniform icon library
- **Tab/index labels** instead of icon buttons for navigation — literal manila folder tabs with typed labels, not icon+text nav bars
- Where you do need a systematic icon set for repeated small actions (expand, close, export), pick ONE consistent set but render it in a single ink color with **irregular corner treatment** (not the default 2px radius) so it doesn't read as a stock icon pack

**Color/surface — reject the dark-purple default entirely**

- Base: warm paper/cork tones — off-white aged paper (#f4ecdc range), cork-brown accents (#8b6f47 range), not black
- Accent: single **deep red** (string, stamps, alerts) — not purple/blue gradient, one committed accent color used sparingly and consistently
- No glassmorphism, no blur, no soft glow — flat matte surfaces with real drop-shadows like actual paper/pins casting shadow (hard-edged, offset, not blurred)
- Redacted content: literal black bar, not a blurred/pixelated effect

**Microcopy/voice — replace SaaS-speak with case-file language**

| Generic AI SaaS | Sleuth |
|---|---|
| "✨ AI-Powered Analysis" | "CASE FILE — CLASSIFIED FINDINGS" |
| "Analyze Now" button | "OPEN CASE" |
| "Get Started" | "BEGIN INVESTIGATION" |
| "Processing..." | "GATHERING EVIDENCE..." typed out, timestamped log lines |
| "92% match" badge | "CONFIDENCE: 92%" stamped, with a "[WHY?]" link |
| "Export Report" | "CLOSE CASE — GENERATE DOSSIER" |
| Toast: "Analysis complete!" | Stamp animation: "CASE CLOSED" |
| Empty state: "No data yet" | "No case opened. Submit a profile to begin." (typewriter) |

**Layout — reject centered-hero-plus-grid**

- No 3-column feature grid with icon-title-subtitle repeated blocks
- Asymmetric corkboard canvas instead of centered card stack — content pinned at varying angles/positions, not grid-aligned
- Navigation via folder tabs along one edge, not a top navbar
- No pricing-table-style comparison layouts — if you need a comparison view (e.g., contradiction display), use the evidence-string visual instead of a table

The through-line: every generic-SaaS convention communicates "software product," and every replacement communicates "physical case file, digitized" — that's the whole differentiator holding together at the smallest visual details, not just the big concept.
